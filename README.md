# 한국스마트공조

냉매 전환·관리 기술 컨설팅 반응형 홈페이지.

## Development
`npm run dev` serves port 3000. `npm run check` validates inline scripts and anchors.

## Deployment
Create a Render Static Site from this GitHub repository: build command `npm run build`, publish directory `dist`, branch `main`. No environment variables are required.

## Design
Editable desktop and mobile concepts: https://www.figma.com/design/2xsOkiX9zsDL4hK9ItqjQc
Navy #0C2636, mint #4DE0D1, neutral #F4F7F6.

## Codex
Open this repository in Codex and follow AGENTS.md. A cloud Codex environment must be selected/created in the user's Codex account; this source package does not create one automatically.

## Contact
The form opens a mailto draft or copies text. It has no delivery backend. Contact information is based on the supplied business card.
