# 한국스마트공조 웹사이트

- Static Korean website in `dist/index.html`; no dependencies or secrets.
- Run `npm run check` after changes. Preview using `npm run dev`.
- Preserve accessible labels, mobile layouts, keyboard navigation, and reduced-motion behavior.
- Never invent certifications, customer names, performance statistics, or regulatory claims.
- Contact form opens an email draft; it does not submit to a server. Do not imply delivery.
- Design reference: https://www.figma.com/design/2xsOkiX9zsDL4hK9ItqjQc
- Render settings: static site, build `npm run build`, publish directory `dist`.
